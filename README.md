## Installation

Download the installer or archive from the [Releases page](https://github.com/nsis-community/plugin-firewall-disabler/releases).

If you downloaded the zip archive, extract it into your NSIS folder: it adds `firewall-disabler.dll` to `Plugins/<variant>/`.
